Optional thumbnails / poster images.

Name an image exactly like its video to use it as the cover:
  logo-animation.mp4  ->  logo-animation.jpg  (jpg, png or webp)
  showreel.mp4        ->  showreel.jpg        (poster for the showreel)

Then run:  node scripts/generate-manifest.js
(If no image is found, the website shows the video's first frame.)
